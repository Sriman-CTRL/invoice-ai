# Trademark filing for "Paivo" in India: draft notes

A working draft for the owner. **It is not legal advice.** I could not run the official availability search (see
[Before you file](#before-you-file-search-first)), so nothing here says the name is free to register.

Last checked: 25 Nov 2026.

## Before you file: search first

Third-party web searches on 25 Nov 2026 found no Indian record for the exact word PAIVO in classes 9, 36 or 42. They showed only
look-alikes (for example PAVO, PAVEO, PAVEVO), mostly through aggregator sites such as registerkaro.in, whose data can be stale.
That is a lead, not a clearance. The official public search needs a person at a browser:

1. Open the IP India Trade Mark public search: <https://tmrsearch.ipindia.gov.in/> (find "Trade Mark Search" / public search).
2. Choose search type "Wordmark". Search `PAIVO`, then the sound-alikes `PAIVOO`, `PAYVO`, `PAIVA`, `PAVO`, `PIVO`, `PAIVU`.
3. Search each against classes 9, 35, 36 and 42, and once with no class.
4. Look for anything that sounds like Paivo for software, invoicing, payments or finance. Note status (Registered, Pending, Objected, Abandoned) and owner.
5. Also check the [Indian Trade Marks Journal](https://ipindia.gov.in/) for marks advertised but not yet registered, and the domain/app-store names.

## Applicant: individual or company

| | Individual (sole proprietor) | Company / LLP |
|---|---|---|
| Official fee per class (see below) | lower | about double |
| Speed | fastest to start | needs the entity first |
| Ownership | the person owns the mark personally; moving it to a company later needs an assignment (more paperwork and fee) | the business owns it from day one |
| Fit | fine while Paivo is run personally | better if a company is planned soon, because assigning later costs time |

Suggested rule: file in the name of whoever will really own and run Paivo for the next few years. If a company or LLP will exist
within months, file as that entity. If not, an individual filing is reasonable. Ask the agent about the small-enterprise/startup
fee conditions before choosing.

## Which classes

| Class | Verdict | Reason |
|---|---|---|
| **42** (SaaS, non-downloadable software) | **File** | Paivo is a web app: temporary use of online software for invoicing is class 42. This is the core class. |
| **9** (downloadable software) | **File** (second) | Covers software or an app that is downloaded. Paivo is web-only today, so this is mostly about a future mobile app and blocking look-alike software names. Say so to the agent; if budget is tight, 42 alone is the one that matches today's product. |
| **35** (business administration, billing and accounting services) | **Optional third** | Invoicing and billing support are business services, which is arguably what the user gets. Worth it if you can afford a third class. The agent should confirm the exact wording the registry accepts. |
| **36** (financial services, payment processing) | **Skip for now** | Paivo never holds, moves or processes money (clients pay the seller's own UPI or bank). Claiming payment services would not match the product, may draw an objection, and costs another fee. Revisit only if Paivo starts handling payments. |

## Goods and services descriptions (draft wording)

Registry descriptions should be plain, specific and true. Draft text for the agent to polish:

- **Class 42:** `Software as a service (SaaS) featuring software for creating, sending and managing invoices and quotations, recording payments received and tracking unpaid invoices; providing temporary use of non-downloadable web-based software for invoicing and payment tracking for freelancers and small businesses.`
- **Class 9:** `Downloadable computer software and mobile applications for creating, sending and managing invoices and recording payments received and tracking unpaid invoices.`
- **Class 35 (if filed):** `Preparation of invoices and billing statements; business administration services, namely, tracking of invoices and payments due for freelancers and small businesses.`

Do not list anything Paivo does not do (no "payment processing", "banking", "lending", "tax filing", "e-invoicing").

## "Proposed to be used" or a first-use date

- The application asks whether the mark is already used or "proposed to be used".
- paivo.in launched in Nov 2026. If you can prove the **first date the public could actually use the service** (a dated sign-up by a real outside user, a dated archive or screenshot, a first invoice), you can claim "used since" that date. A date you cannot evidence can cause trouble later.
- If in doubt, choose **proposed to be used**. It is always true, and a use date can be claimed later when you file evidence. A prior-use date matters only if someone else is competing, so it is not worth guessing.
- Keep the evidence either way: launch date, first outside sign-up, dated screenshots of paivo.in with the name.

## Which logo file to attach

- Start with the **word mark `PAIVO` in standard characters** (typed text, no logo). It protects the name in any style and is the broadest and cheapest first filing.
- If you also file the logo, use the wordmark in **black on a white background**: `brand/logo/paivo-wordmark-black.svg` (the source of truth is `brand/build_kit.py`). The online form takes an image (JPG), so export a clean black-on-white JPG of that SVG at a modest size and check the portal's current size limit. Do not attach the coloured or dark-background variants, the standalone P symbol or the tagline.
- The primary logo is the wordmark; the P symbol is a separate mark and would need its own filing if you want it protected.

## Steps to file online

(Portal screens change; follow the live prompts and ask the agent if one is unclear.)

1. Finish the search above and decide the applicant, the classes and the use date.
2. Open the e-filing portal from <https://ipindia.gov.in/> (Trade Marks, online filing) and create a user account. The portal may ask for a digital signature certificate (DSC) to sign; check the current requirement.
3. Choose the application form for a trade mark (TM-A) for a word mark or device mark; pick "e-filing".
4. Enter applicant details (name, address, entity type, and email you will keep checking).
5. Enter the mark (typed word, or upload the logo image), then the class and the description text for each class.
6. State "proposed to be used" or the first-use date.
7. If an agent files for you, add the power of attorney (the agent will arrange it).
8. Pay the fee online per class and download the receipt and the application number.
9. Afterwards: the registry examines the filing and may raise an objection to answer within the time given; the mark is then advertised in the Journal for opposition. Keep checking the email and the status page. You can use "TM" next to the name from filing; use the registered symbol only once it is registered.

Have a registered trademark agent or attorney confirm before filing.
